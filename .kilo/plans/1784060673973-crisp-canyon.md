# Root Cause Analysis: YouTube Player Timeout

## Issue
Infinite loader on movie page due to YouTube player creation failure with "Error: YouTube player timed out" message

## Root Cause
The `PlayerManager.parseYoutubeId()` function uses an overly broad regex that matches non-YouTube URLs containing YouTube-like patterns:
```javascript
const regExp = /^.*(youtu.be\/|v\/|u\/\w\/|embed\/|watch\?v=|&v=)([^#&?]*).*/;
```

This causes incorrect YouTube adapter selection when:
1. Server URL contains YouTube-like patterns but isn't actually a YouTube URL
2. Regex finds 11-character substring matching YouTube ID pattern within non-YouTube URLs
3. `PlayerManager.create()` attempts YouTube player creation for invalid URLs
4. YouTube API fails to load or video doesn't exist, causing timeout

## Verification
- Confirmed error occurs during YouTube player creation
- Debug logs show YouTube adapter is created even when server.type ≠ 'youtube'
- Timeout occurs during YouTube API loading phase

## Solution
1. **Precise URL validation**: Only attempt YouTube player creation when server.type explicitly indicates YouTube URL
2. **Enhanced error handling**: Automatic fallback to next server when YouTube creation fails
3. **Timeout protection**: Already implemented with 10-second timeout
